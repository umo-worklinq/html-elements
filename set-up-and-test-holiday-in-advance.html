1. First, check that the holiday account has the correct advanced settings. Go to System → Accounts → Accounts
  2. Select the main holiday account, normally X300, and go to the Advanced settings tab
  3. Scroll down to the section on Minimum balance, and see that it is set to 0
  4. At the bottom, the setting Running check should be checked
  5. Go to the Web portal and navigate to the web part Calendar
  6. Select an employee, and attempt to register 6 weeks of holiday. You should get an error.

  7. Next, we need to create and set a value for an employee figure. Go to System → Employee Figures
  8. Click the blue plus to create a new employee figure with these settings:

    9. Type Regular figure
    Id ADVHOLIDAY
    Description Holiday in advance
    Definition level Employee, Category, and System
    Available to account formulas ✓

  9. Go to System → Employee
  10. Select the employee that you wish to grant holiday in advance
  11. Click Rates
  12. Click the blue plus to add a new rate with these settings:

    13. Rate id ADVHOLIDAY
    Rate -25
    From 01/01/2025
    To

  13. Save it, and test again in the web portal, by repeating step 5-6

Note: The From and To dates should in a real life scenario be set so the exception is only valid until the employee has accrued enough holiday to not need the holiday in advance.

Example: Employee has accrued 4.16 days of holiday in October. They wish to register 1 week of holiday, requiring 5 days. The ADVHOLIDAY value is set to -1 from Oct 1 until Nov 1, where they accrue another 2.08 that can cover the "loan".
