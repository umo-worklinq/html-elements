1. Go to Applications → Web portal → Layout setup
  2. Select either Employee role: System or Category, depending on your current setup (if there are category setups, you should update those).
  3. If configuring at Category level, first select a category from the list, or click the blue plus to add a new category specific configuration.
  4. Click the pencil icon next to the first greyed out item in the menu list
  5. Set the Description to Holiday
  6. Set the Icon to Briefcase
  7. Search for Holiday overview in the Web parts field
  8. Click OK and hit the save icon
