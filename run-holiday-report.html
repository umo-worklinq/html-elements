If you do not already have the Reporting web-part added to the web portal:

  1. Go to Applications → Web portal → Layout setup
  2. Select either Manager role: System or Manager profile, depending on your current setup (if there are Manager profile setups, you should update those).
  3. If configuring at Manager profile level, first select a profile from the list, or click the blue plus to add a new profile specific configuration.
  4. Click the pencil icon next to the first greyed out item in the menu list
  5. Set the Description to Holiday overview
  6. Set the Icon to Briefcase check
  7. Search for and add Holiday overview and Holiday management in the Web parts field
  8. Click OK and hit the save icon

Pull the Holiday report through the Reporting web-part:

  1. In the Web portal, go to the menu where you have your Reporting web-part
  2. Click Absence to open the list of absence related reports
  3. Select the report Holiday Overview from the list
  4. Double-click it, or click Run in the top left
  5. You may leave the Report settings as they are, and click NEXT
  6. Specify the date at which you would like to see the status. Note that it is not possible to see accrual of holidays in future holiday periods that have not yet begun.
  7. Click NEXT
  8. You may skip to specify an Employee filter. Click NEXT
  9. Click Add and type in a name for a Holiday Type filter in the Filter field to the left.
  10. Select the Holiday type you previously created in the Value field below, and click Save above
  11. Click RUN
