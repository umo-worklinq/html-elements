1. Go to System → Job Scheduler
  2. Click the blue plus in the top left to create a new scheduled job
  3. In the Job Type, search for Holiday and select Holiday Calculation
  4. In the description field, write Holiday Calculation 2025
  5. Set Recurrence to All days and set the Start time to a 02:00.
  6. In the Properties tab, set the Holiday year to 2025, and the Number of days with log history to 5
  7. Click the save icon. The job will run immediately
