1. First, we need to create the accounts required for the new holiday type
  2. Go to System → Accounts → Accounts
  3. Click the blue plus to create new accounts according to the table below
    4. Id Description Account type Account unit Reset
    A320 Seniority holiday Employee account Days Periodically
    X320 Seniority holiday balance Employee account Days None
    Z321 Seniority holidays not used Employee account Days Periodically
    Z322 Seniority holidays above maximum Employee account Days Periodically
    Z323 Seniority holidays encashment account Employee account Days Periodically

  4. Next, go to Profiles → Holiday Management → Holiday Types
  5. Click the blue plus to add a new Holiday type
  6. Fill the basic settings according to the table below
    7. Id EXTRA-HOLIDAYS-AGE
    Description Seniority days
    Accruing value Fixed value
    Holiday period from Month after birth
    Accruing period, one year from January
    Allocate accrued holidays at Beginning of the period
    Length 12 months

  7. Click the save icon
  8. Click Category
  9. Create a new category setup by clicking the blue plus

  10. Fill the General settings according to the table below
    11. Category
    Valid from Choose the current year
    Main Account X320

  11. At the bottom of the page, click + Add and fill the settings according to the table below
    12. Year 60
    Number of days/hours 2

  12. Click the Transfer/payout tab in the top, and fill the settings according to the table below
    13. Total maximum days to transfer 5.00
    Transfer remainder to account Z320 - Seniority holidays not used
    Transfer remainder above maximum to Z320 - Seniority holidays not used

  13. At the bottom + Add the options you wish to be able to select as an administrator when transferring holidays.
  14. Click save
  15. Go to System → Employee and select an employee that should be more than 60 years old
  16. In the Personal tab of their settings, fill the Birth date with a date that is more than 60 years ago
  17. Go to System → Job Scheduler
  18. If you don't already have a holiday calculation job for the current year, create one, otherwise, run it.
  19. Go to the web portal, find the Holiday Overview web part, and check that the employee you selected has received the appropriate amount of holidays.
