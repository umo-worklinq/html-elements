1. Go to System → Notification set-up
  2. Click the blue plus to create a new notification setup with these settings in the General tab:

    3. Publisher Holidays
    Reference Select the Holiday type you created earlier
    Description Holiday
    Type Message
    Receivers ✓ Employee

  3. Save, and go to the Templates menu in the top right
  4. Click the blue plus to add a new Template with these settings, as an example:

    5. Id PortalRemainingHoliday
    Subject Remember to spend holiday!
    Greeting Dear ﻿@Employee First name﻿﻿,
    Body Please remember to spend your remaining holidays.
    Repeating body You have ﻿@Remaining holidays﻿﻿ days remaining of the type ﻿@Holiday type﻿﻿.
    Signature

  5. Save it, go back to the notification setup page, and then go to the Delivery service tab
  6. Put a tick in Portal/Mobile and select the template you just created (Id: PortalRemainingHoliday)
