1. Go to System → Notification set-up
  2. Click the blue plus to create a new notification setup with these settings in the General tab:

    3. Publisher Holidays
    Reference Select the Holiday type you created earlier
    Description Holiday
    Type Message
    Receivers ✓ Employee

  3. Save, and go to the Templates menu in the top right
  4. Click the blue plus to add a new Template with these settings:

    5. Rate id ADVHOLIDAY
    Rate -25
    From 01/01/2025
    To

  5. Save it, and test again in the web portal, by repeating step 5-6

Note: The From and To dates should in a real life scenario be set so the exception is only valid until the employee has accrued enough holiday to not need the holiday in advance.

Example: Employee has accrued 4.16 days of holiday in October. They wish to register 1 week of holiday, requiring 5 days. The ADVHOLIDAY value is set to -1 from Oct 1 until Nov 1, where they accrue another 2.08 that can cover the "loan".
